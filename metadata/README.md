# Metadata

- `metadata.csv`: Sample information for 120 fecal samples collected from 30 dairy cows at D0, D30, D60, and D90.


Treatment groups:
- ITM: 100% inorganic trace minerals
- OTM1: 50% inorganic + 50% methionine-hydroxy-analog-chelated trace minerals
- OTM2: 50% inorganic + 50% amino-acid-chelated trace minerals
