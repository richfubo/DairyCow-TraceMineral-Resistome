This repository contains scripts and processed datasets supporting the study "Amino acid–chelated trace minerals remodel the fecal metal resistome without increasing antibiotic resistance burden in dairy cows." The project integrates 16S rRNA gene sequencing and shotgun metagenomics to characterize fecal microbial communities, antibiotic resistance genes (ARGs), metal resistance genes (MRGs), mobile genetic elements (MGEs), and functional pathways during a 90-day feeding trial with different trace mineral formulations.
